# Recursos visuales

El personaje humano `public/models/human/human.glb` procede del `parametric-base.glb` de three.ws, creado a partir de datos MakeHuman/MPFB2 CC0. La licencia y procedencia detalladas están en `public/models/human/LICENSE.txt` y `public/models/human/SOURCE.txt`. Tres poses MakeHuman CC0 se almacenan por separado en `public/poses/`; sus fuentes figuran en `POSES.md`. No se incluyen recursos de Posemaniacs.

La fuente tipográfica se carga desde Google Fonts: [DM Sans](https://fonts.google.com/specimen/DM+Sans) y [Playfair Display](https://fonts.google.com/specimen/Playfair+Display), publicadas bajo la [SIL Open Font License](https://openfontlicense.org/).

El sitio utiliza únicamente las poses riggeadas del manifiesto. Si el GLB o una pose no se pueden cargar, la práctica muestra el error y no inicia el temporizador.
